# 音频实验室

入口：音乐库或头像菜单 → 音频实验室，地址 /audio-studio。路由与分析 Worker 均按需加载，推理运行时和模型不进入首页加载链路。

## 多设备同步音响

所有设备登录同一网易云账号，打开音频实验室。第一台创建播放组，其他设备点击「加入并启用」。每台设备需一次用户操作以解锁音频输出。主持设备导入当前可完整播放的网易云歌曲，或上传本地音频；每台设备取得同一份 SHA256 校验过的音源并完成解码后，主持设备才能同步播放。

提供全组暂停、定位、主持权转交、每设备音量、立体声/左声道/右声道与 -1000 至 1000ms 延迟补偿。生成并选择「校准节拍」后，等待设备准备好再同步播放；负补偿提前、正补偿延后。主持设备退出会暂停并将主持权交给剩余设备，所有成员离开后播放组关闭。

音源临时上传到账号隔离的私有目录，单文件32MiB、最长10分钟、每账号最多8份及128MiB、全局256MiB和256份；并发上传预留配额，超额或异常会清理未完成文件。两小时未使用后过期。播放组为实时会话，服务重启后需要重新创建，不改变网易云歌单。

对时使用 performance 时钟的往返采样，选择低RTT样本；共同起播时间由服务端确定。使用 AudioContext.getOutputTimestamp 映射输出时钟，缺失时按设备延迟估计。持续检查软件调度漂移，轻微偏差通过小幅速率修正，大偏差重新对齐。音响挂起、断线、退出、维护均处理相应播放状态；恢复页面不自动发声。

界面的「对时估计」「调度偏差」是软件指标，不等同声学同步精度。声卡、蓝牙和设备摆放均会影响实际声音，须使用真实设备校准，不能把同机多浏览器测试当作不同硬件的精度证明。

## 可交互空间混音台

可直接导入本地歌曲并选择一段15/30/60秒音频或整首处理，最长5分钟；也可导入起点一致、时长相同的 vocals/drums/bass/other 四个独立声部。首次分离会下载约172MiB模型，完整验证SHA256后缓存于本机 IndexedDB。音源分离在本机 Web Worker 内通过 ONNX Runtime Web WASM 运行，单线程无需启用跨源隔离。缓存仅保存公开模型，不保存用户音频。

真实 Demucs 分离得到四声部。STFT使用原始Demucs反射padding、标准化和帧裁剪，频谱分支经过iSTFT后与时间分支合成，分块之间加权重叠。分析进度由实际已完成分块计算，模型初始化阶段不虚构百分比。取消或离页会中止网络、终止Worker并释放引用；开始新的分离前清理旧声部缓冲。

每个声部进入独立 HRTF PannerNode，可拖动前后左右、调节高度，支持音量、静音、独听与WAV声部导出。四个声部共享起播时刻和播放进度，经过主音量和动态压缩。建议使用耳机。布局按账号保存在本设备，不上传音频或混音内容。AI分离可能存在串音、瞬态损失或伪影，耗时与内存占用取决于设备；不宣称实时或无损分离。

本地文件不因分离而上传。从播放器导入歌曲时会经过服务器临时获取音源，界面对此有说明。空间混音、同步音响和普通播放器互斥，新的普通播放意图会停止实验室本机音频。

## 维护与安全

页面 page.audioStudio 和功能 feature.speakerGroup、feature.spatialMixer 三端维护目录一致。操作执行前后、异步结果回写前均检查生命周期、账号与维护状态；关闭维护弹窗不能恢复被禁用功能。注销、账号切换和离页清理私有数据、音频节点、Worker、请求及SSE。

专用内存会话通过真实网易云身份验证换取，服务端仅存随机令牌的哈希。私人接口不接受旧JWT、查询参数令牌或请求体UID。公开模型不含账号信息并使用长缓存；私人音源及状态 no-store。原始Cookie仅在身份交换与固定上游导入时使用，不进入音源文件、URL或事件。

模型与依赖出处、哈希和许可证见 public/audio-studio-licenses.txt。
