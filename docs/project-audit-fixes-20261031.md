# 2026-10-31 审查修复

此次修复覆盖维护同步、异步请求隔离、统计上报、后台操作一致性及资源使用。

| 范围 | 修复后的行为 |
| --- | --- |
| 维护 | SSE 实时推送；15 秒心跳、断线重连；异常时恢复北京时间整 10 秒检查；自定义维护页和中央功能提醒沿用原设置 |
| 扫码登录 | 检查串行；刷新、关闭中止请求；旧二维码和旧账号响应失效；同步成功后才记录同步冷却时间 |
| 用户数据 | 私信按账号和会话隔离；个人中心、歌单收藏和喜欢响应不能修改后来切换的页面或账号 |
| 播放与停留 | 同一次播放按 sessionId 幂等更新，单曲循环创建新会话；拖动进度不算真实收听，后台停留不计入前台时长 |
| 音源与歌词 | 缓存有容量和有效期；音源请求合并并按账号隔离；歌词优先精确歌曲 ID，仅下载最佳候选，切歌取消旧请求 |
| 喜欢与收藏 | 上报包含取消状态，唯一键去重，统计及列表只读取当前有效记录 |
| 管理端 | 旧保存响应不会关闭新编辑窗；详情切换取消旧请求；会话先刷新；禁用、风险用户可恢复正常 |
| 上传 | 替换或关闭表单会中止上传；首帧提取 15 秒超时；60 秒无进展中止上传，结束即停止进度查询 |
| AI | 诊断去重、单并发和超时；任务按增量进度更新，历史列表不加载报告正文，隐藏标签页暂停检查 |
| 统计 | 看板缓存 15 秒，活跃用户跨来源去重，业务日期按北京时间，访问分组按访问次数求和，计数原子更新 |
| 权限与限流 | 限流计数原子递增，超限不会重置窗口；管理员修改在事务内锁定管理员账号，避免并发移除最后一位可用管理员 |
| 历史回滚 | 歌单恢复删除标志和排序；Banner、MV 首帧按内容哈希归档并随版本恢复，图片 URL 带版本避免旧缓存 |

## 发布和数据库

1. 备份数据库，运行后端仓库的 `database-migration-audit-fixes-20261031.sql`。脚本可重复执行，不删除历史行；会补充播放会话、偏好状态、访问幂等键、媒体版本和首帧归档表及唯一索引。
2. 依次发布后端、管理端、用户端。新后端仍接受旧客户端没有 sessionId 或取消标志的请求。
3. 所有后端实例更新后可重复执行迁移，规范升级期间旧服务新写入的偏好行；已取消状态不会因重跑迁移重新激活。
4. 检查状态 GET、SSE 初始事件与心跳、前台恢复以及管理端资源。不要为发布验证修改真实维护开关。

历史播放没有会话 ID，历史喜欢、收藏没有取消事件，无法精确还原过去状态；已丢失的历史视频首帧也无法恢复。迁移保留历史行，较早的重复偏好行标记为 inactive。首次编辑升级前媒体时会归档当前首帧并补入匹配的历史快照；缺少可还原首帧的旧快照回滚后不沿用错误首帧。
