# 2026-10-21 性能与体验优化

本轮主要处理启动时的非必要加载、搜索和筛选的异步竞态，以及媒体组件的资源生命周期。

## 改动

- 开屏只等待当前路由、必要资源与首帧；字体等待限制为 1.2 秒。移除逐帧检查资源下载进度的轮询，组件卸载时取消观察器、动画帧和计时器。
- 常用路由在启动后延迟进入空闲预热，每次只加载一个；省流量、2G 和隐藏页面跳过预热。完整歌词模块不参与预热。
- AMLL、Folia 在打开全屏时按需加载，取消选中歌曲就挂载隐藏歌词播放器的行为。增加等待、重试和返回入口，保持键盘焦点与 Escape 退出。
- 搜索在输入变化、清空、发起新请求和卸载时取消旧请求，同时保留响应编号校验。中文输入法确认前不提交搜索；同一关键词可再次提交。组合搜索全部失败时显示错误。
- 发现页的专辑、艺人、榜单、曲风与播客处理旧响应和卸载后的回写；快速切换播客分类共享分类目录请求，部分接口失败有明确提示。
- SmartMedia 保留仍在使用的 Blob URL，回收已移除的 URL，修复重复使用已撤销地址的问题。隐藏页面和停用的缓存页面停止文本轮播与滚动监听，减少动态效果设置同时作用于轮播和滚动缩放。
- 开发性能监控改为显式开启：设置 `VITE_ENABLE_PERF_DEBUG=true`。默认不运行其持续帧率采样。

## 启动测量

使用本地生产构建 `/search`，Chrome 无头浏览器，1440 × 1000，禁用 HTTP 缓存，CPU 降速 4 倍，网络延迟 40ms，下载 1,500,000 bytes/s。记录开屏退出、页面解除 inert 时的资源情况。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 页面解除开屏阻挡 | 3.21 秒 | 1.11 秒 |
| 此前完成加载的 JS 请求数 | 41 | 20 |
| 此前完成加载的 JS 解码大小 | 2.61 MB | 0.83 MB |

这是同一模拟条件下的单次本地观测，不是线上统计或所有设备的性能承诺。JS 解码大小是 Resource Timing 的 `decodedBodySize`，不是 gzip 传输大小，也不是整个应用的构建体积。首次打开歌词播放器需要下载对应模块，界面会显示加载反馈。

## 验证

- `npm run build`：生产构建。
- `npm test`：44 项测试全部通过，包含新增的 10 项启动和异步状态回归测试。测试文件顺序执行，避免 Vite 实例争用调试端口和 GIF worker 在并行构建时超过测试时限。
- 修改的应用 JS/Vue 文件通过 ESLint，`git diff --check` 无空白错误。
- 浏览器验证中文输入提交、快速搜索、清空待完成搜索、390px 窄屏、AMLL 与 Folia 首次打开和关闭、Escape、Blob URL 复用和回收、动态减少动画偏好。
- 使用本地静音 WAV 验证全屏播放器打开与关闭期间音频持续播放；专用浏览器未捕获到未处理异常。

浏览器的搜索 API 使用固定响应，音频使用本地文件；真实账号登录、付费音源和线上音乐服务未进行端到端验证。
