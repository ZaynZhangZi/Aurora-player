# 首次加载与等待互动

HTML 先加载约 16 KB 的独立 `public/aurora-loading.js`，因此主应用还在下载时就能显示唱片与音波动画。该脚本不依赖框架、图片、字体或其他资源下载；Vue 开屏组件只负责传入真实启动进度和完成信号。

- 等待 1.6 秒后显示 Do / Re / Mi / Sol 四个音符，可点击、触摸或使用 A / S / D / F。
- 默认静音，主动开启声音后才创建 Web Audio 音频上下文。切到后台暂停动画和声音，退出加载界面时释放音频、监听器与定时器。
- 等待 12 秒后出现重新加载入口，用户也可以继续弹奏。
- 页面就绪后自动淡出；较慢的真实加载不会再叠加最短展示时间。使用过互动控件时，进入页面后恢复键盘焦点。
- 支持减少动态效果设置，此时保留静态反馈和音符互动。同一会话再次打开时直接结束等待界面。
- 全屏歌词播放器的加载状态也使用轻量音波动画。

验证：生产构建、修改文件的 ESLint 和 44 项现有回归测试通过。浏览器中主动阻止主入口 JS 下载，确认 Vue 尚未启动时界面和互动已经可用；覆盖键盘、声音开关、快速连续点击、后台暂停、12 秒等待、焦点交接、重复访问及减少动态效果设置。1440 × 1000、390 × 844 和 320 × 568 均已检查；页面就绪后加载界面移除，试听音频上下文关闭，无未处理异常。
