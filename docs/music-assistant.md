# AI 音乐助手

入口：主导航「AI 选歌」、手机导航的星形按钮，或个人菜单。路由 `/music-assistant` 按需加载，不进入首页依赖链。

使用官方网易云音乐 CLI 授权读取音乐数据。点击「连接网易云音乐」，扫码或打开官方链接，在网易云音乐中确认授权。该授权与本站当前登录状态独立；播放仍交给现有网页播放器，沿用本站当前账号的播放权限。

对话支持描述场景、心情、艺人，或继续调整上一份结果。后端先搜索真实歌曲，再由模型筛选；返回 ID 必须来自本连接已验证的结果。未实际读取收藏时，不声称推荐来自收藏。当前授权开放的收藏读取和歌单功能会根据官方命令能力显示。

推荐卡片支持播放、加入当前队列；歌单写入由用户主动点击保存发起，模型没有写歌单权限。服务器会检查所选歌曲、创建歌单、写入并回读验证；重试同一次保存会复用已创建的歌单，避免重复创建。写入和回读能力缺失时不会显示保存按钮。

新对话会清除本连接的模型上下文和候选歌曲，保留官方授权。断开官方账号会撤销本站连接、停止后续任务并清理服务端私有临时凭证。本站退出登录或切换账号也会撤销连接，包括已经离开助手页面的情况。关闭页面停止当前任务；同一标签页重新进入可恢复仍有效的连接。

维护项为 `page.musicAssistant`、`feature.musicAssistant`，同时遵守通用 `feature.ai` 与播放能力的维护限制。维护中禁用入口和实际操作，关闭提示不会恢复权限。

模型密钥、网易应用私钥和官方登录凭证均留在服务端；浏览器只持有本标签页的随机连接令牌。令牌不进入 URL 或日志。对话正文和必要歌曲信息会发送到所配置的模型服务，应用凭据不发送给模型。

参考网易官方 [Agent Skills](https://github.com/NetEase/skills) 的音乐助手流程。技能文档采用 Apache-2.0；官方 `@music163/ncm-cli` npm 包声明为 MIT，适配器固定版本 0.1.7。本站的页面、用户隔离、权限控制和模型编排为项目独立实现。
