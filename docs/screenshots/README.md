# README 截图与动效素材

素材来自 [AuroraPlayer 线上站点](https://music.xiaojunjunjun.com/)，采集日期为 **2026-10-09**，浏览器视口与输出分辨率均为 **1920 × 1080**。

静态截图在页面主要内容、可见封面及字体加载完成后拍摄，并等待进入动画结束。页面使用真实线上数据，未替换接口响应或伪造登录状态；采集时使用游客模式，不含账号凭证与私信内容。

| 文件 | 内容 |
| --- | --- |
| `fullscreen-player.webp` | 正在播放的全屏歌词、封面、播放控制与流体背景 |
| `fullscreen-motion.webp` | 约 6.5 秒的真实录屏：展开全屏、歌词流动、收起播放器；20 fps、循环播放、无音轨 |
| `home.webp` | 首页推荐电台、继续播放、队列与听歌场景 |
| `discover.webp` | 发现页的本周新声与浏览入口 |
| `search.webp` | Taylor Swift 综合搜索与最佳匹配 |
| `artist.webp` | Taylor Swift 歌手主页 |
| `album.webp` | 从歌手主页打开的专辑详情浮层 |

静态图片使用 WebP 保留原始分辨率并控制文档体积；动态预览使用 Animated WebP。采集工具和中间帧保存在本地 `tmp/`，不随源码提交。

更新素材时，请保持文件名与主 README 中的引用一致，确认封面、歌词、曲目和相关媒体已经加载完成，并重新检查分辨率。推荐内容、歌曲可用性和页面表现可能随线上版本、API 与账号状态变化。
